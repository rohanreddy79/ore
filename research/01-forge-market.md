## 5. Version-control-layer innovation

- **Git releases:** 2.50 (Jun 16, 2025): ORT becomes the only merge engine, incremental multi-pack bitmaps, new `git maintenance` tasks, `reflog drop`, Perl no longer required (https://github.blog/open-source/git/highlights-from-git-2-50/). 2.51 (Aug 18, 2025): cruft-free MIDX, `--path-walk` repacking (smaller packs), `git stash export/import`, `switch`/`restore` stabilized, `whatchanged` deprecated, a build flag to preview Git 3.0 defaults (https://github.blog/open-source/git/highlights-from-git-2-51/). 2.52: SHA-1/SHA-256 interop (`compatObjectFormat`) begun, Rust auto-detected (https://github.blog/open-source/git/highlights-from-git-2-52/). Latest stable reportedly 2.55 with 2.56 in RC (Sep 2026; UNVERIFIED).
- **Git 3.0 (no date):** SHA-256 default for new repos *only once "Git libraries, applications, and forges" are ready*; reftable default (needs JGit/libgit2/Gitoxide); `main` default; **Rust mandatory** (default-on in 2.55); `safe.bareRepository=explicit`; removals (grafts, `pack-redundant`, `whatchanged`); last 2.x will be an LTS (https://git-scm.com/docs/BreakingChanges). GitButler argues the SHA-256 default is "a costly mistake" (https://blog.gitbutler.com/git-3-sha-256). **Forge support is the explicit gating factor** — none of the big hosts advertise SHA-256 repos today.
- **Jujutsu (jj):** Rust, Apache 2.0, 30k+ stars; monthly releases, v0.46.0 Oct 7, 2026 (colocated workspaces via git worktrees, push to multiple remotes) (https://github.com/jj-vcs/jj/releases); Google uses internally ("not a supported product"); creator left Google for ERSC (above). Forge integration still WIP — stacks pushed as plain git branches.
- **Sapling (Meta):** git-compatible client, first-class stacks, ghstack for GitHub; server (Mononoke) not offered publicly (https://sapling-scm.com/). **Pijul:** commutative patch theory, partial clones for monorepos, 1.0-beta line, own host "the Nest" (https://pijul.org/).
- **Stacked-diff tooling:** Graphite (gt CLI, merge queue, "Diamond" AI reviewer; "hundreds of thousands of engineers") now inside Cursor; spr, git-branchless, ghstack, Aviator remain independent. Independent 2026 benchmark put Graphite's Diamond last of 7 AI reviewers (3.3% recall) (https://tenki.cloud/blog/graphite-cursor-independent-code-review — vendor-run, treat cautiously). GitHub's own merge queue reverted 2,092 PRs in an April 2026 regression.
- **What "better than git while git-compatible" means in practice:** server-side awareness of jj/Sapling change-IDs and stacks (PR = stack, not branch); first-class recorded conflicts; SHA-256 + interop + reftable support ahead of Git 3.0; partial/sparse clone and LFS that scale (Forgejo just overhauled LFS; CodeCommit's #1 request was LFS); op-log style undo for forge operations; cryptographic identity for humans *and* agents (Radicle/Tangled model; GitHub Agent HQ "agent identity"; Gitea 28 bot accounts).

## 6. Migration pain and tooling

- **GitHub → GitLab:** GitLab importer needs each author's public GitHub email to match a GitLab email or history is attributed to one migration account; approvals dropped/flattened, inline comment anchors lost on diff rebuild, status-check rules not recreated; Actions → `.gitlab-ci.yml` is manual (matrices, permissions, environments, caching, Marketplace gap); packages/releases don't follow (https://migratingto.dev/guides/github-to-gitlab/, https://migratingto.dev/guides/github-actions-to-gitlab/, https://sourcex.si/insights/migrating-between-github-gitlab-and-bitbucket-keeping-pull-request-review). Motivation example: "$800/month Actions → $0 GitLab CI" (https://medium.com/lets-code-future/github-actions-cost-us-800-month-gitlab-ci-costs-0-c5188f660cd4).
- **GitLab → GitHub:** `gh gl2gh` (GEI extension) **GA Aug 3, 2026**: migrates git, wiki, issues, MRs→PRs (reviewers/approvers; review comments only if export has diff data, latest diff only), milestones, releases; does NOT migrate pipelines/variables/schedules/artifacts/webhooks, LFS binaries, merge trains, required approvals, group membership, snippets, boards, time tracking; 40 GiB repo cap, 2 GiB commit, 400 MiB file; GHEC only (https://www.developersdigest.tech/blog/github-gl2gh-gitlab-migration-ga-2026).
- **GitHub → GitHub (GEI):** does not move Actions secrets/variables/environments/runners/run history, Packages, Projects (new), Discussions, rulesets, LFS objects, stars/watchers, fork relationships, webhook secrets, GitHub Apps, code-scanning/Dependabot alerts, sub-issues, several branch-protection modes; 40 GiB limits (https://docs.github.com/en/migrations/using-github-enterprise-importer/migrating-between-github-products/about-migrations-between-github-products). Sources supported: ADO Cloud, Bitbucket Server/DC 5.14+, GitHub.com, GHES 3.4.1+, GitLab (https://docs.github.com/en/migrations/using-github-enterprise-importer/understanding-github-enterprise-importer/about-github-enterprise-importer).
- **→ Self-hosted Gitea/Forgejo:** built-in migrators from GitHub, GitLab, Gitea, Gogs, OneDev, Codebase, GitBucket, Forgejo; Forgejo 17 adds Bitbucket Data Center and avatar migration (https://forgejo.org/2026-10-release-v17-0/). Practical gaps: Zig chose *not* to migrate issues/PRs and offset numbering; Actions YAML only partly compatible (Forgejo docs); Codeberg has no free hosted-minutes equivalent (Woodpecker/Forgejo Actions on volunteer infra).
- **Universal pain:** identity mapping (mannequins), CI secrets/history, LFS binaries, permissions/rulesets, approvals, redirects/link rot, and issue-number continuity.

## Gaps and opportunities a new forge could exploit

1. **Reliability as the headline feature.** GitHub logged 257 incidents / 112 h of major downtime in 12 months, Actions worst-hit, and reliability is the #1 reason cited by Zig and HN switchers. Ship an SLA on CI start latency (GitHub's Oct 5, 2026 incident: 26.5% of jobs not started in 5 min), public per-service error budgets, and multi-region active-active git.
2. **Predictable, model-agnostic AI pricing.** Copilot's June 2026 token billing produced 10–50x bill shocks and ~900-downvote threads; GitLab's credits are a "limited-time promotion." Offer flat per-seat AI with hard budgets, BYO-model/API-key and local-model support, and per-repo AI spend caps.
3. **Self-hosted runners free, contractually.** GitHub attempted a $0.002/min tax on *customers' own* compute and had to retreat. Guarantee zero platform fees for BYO runners in the license, with first-class ARM, warm caches, and autoscaling (Gitea's k8s autoscaling is paywalled).
4. **True GitHub Actions compatibility.** Forgejo documents that its Actions "are not the same" and lists a dozen gaps; Gitea 28 tightened semantics; GitLab needs full rewrites. A forge that runs unmodified GitHub workflows + Marketplace actions (with a public conformance suite) removes the single largest migration blocker.
5. **Built-in end-to-end deployment.** No major forge owns deploy: GitHub stops at Actions/Pages, GitLab has environments but sells Duo credits, Harness OSS bundles pipelines+registry but is vendor-steered, Origin is review-centric. Preview environments per PR, GitOps rollouts/rollbacks, built-in registry and secrets, cost visibility — inside the forge — is unoccupied ground (and the founder's thesis).
6. **High-fidelity migration.** Every importer drops CI secrets/history, LFS binaries, approvals, rulesets, stars, webhook secrets; gl2gh only arrived Aug 2026 and skips pipelines. A migrator that preserves issue numbers (Zig had to start at #30000), reclaims identities, translates CI, and leaves redirects/mirrors behind is a wedge.
7. **UI performance budgets.** HN's 1k-comment thread documents diffs failing >5k lines, 3–4 s notification loads, broken back navigation, un-searchable Actions logs, and an ex-GitHub engineer confirming a failed year-long perf effort. Server-rendered, instant diffs/log search is a measurable differentiator.
8. **Sovereignty-first architecture.** Dutch and German governments picked Forgejo/GitLab for control and all-features-free licensing; GHEC residency covers only 4 regions. Ship self-host-first with managed EU/sovereign-cloud regions, GPL/AGPL, and trademark held by a non-profit (the Gitea→CommitGo trademark grab is the cautionary tale).
9. **Kill the SSO tax.** SAML/SCIM is Enterprise-only at GitHub ($21+ after a 12-month teaser), $29 at GitLab, $9.50–19 at Gitea Enterprise. Free SSO/audit logs for small teams converts the mid-market that resents the cliff.
10. **Native stacked diffs + jj/Sapling awareness.** Graphite was bought by Cursor; Origin's beta still lacks stacks and merge queue; GitHub's merge queue reverted 2,092 PRs in April 2026; jj has no first-class forge. Model a PR as a stack of change-IDs with recorded conflicts and a correct merge queue.
11. **Be the first SHA-256/reftable-ready forge.** Git 3.0 is explicitly blocked on forge readiness; nobody large advertises SHA-256 repos or interop. Early support is cheap credibility with the Git community and future-proofing for enterprises.
12. **Agent governance and provenance.** Agent HQ adds agent identity; Gitea 28 adds bot accounts and audit logs; Codeberg is *banning* LLM-heavy projects. Offer per-repo AI policies (no-training flag honored and audited, agent-authored commit provenance, bot CI budgets, approval gates for agent PRs) rather than a ban or a free-for-all.
13. **Rate limits and scraping without punishing humans.** HN users report GitHub rate limits "on nearly every click" and Codeberg's bot interstitials blocking legitimate access. CDN-cached public views, signed-in fast paths, and transparent limits are a UX gap on both sides.
14. **Portable sponsorship.** Zig calls GitHub Sponsors "a liability"; Forgejo 17 only adds a FUNDING.yml button. Built-in, exportable sponsorship with Open Collective/Every.org rails and no platform lock-in appeals to the exact maintainers who are leaving.
15. **Lightweight footprint for mid-size orgs.** GitLab wants 8 vCPU/16 GB for 1,000 users; Gitea runs in ~1 GB. A single-binary forge with Postgres/SQLite and built-in CI/deploy that a two-person platform team can run is what public-sector and SMB buyers (Dutch SSC-ICT) actually operate.
16. **Fill the hyperscaler vacuum.** GCSR is end-of-sale, CodeCommit flip-flopped (and still lacks LFS until 2026), Azure DevOps is on minimal investment. A VPC-deployable forge with native cloud IAM, CloudTrail-style audit, and air-gap support targets regulated buyers the SaaS forges underserve.
17. **Learning built into the forge.** 36M new developers/yr, 80% using Copilot in week one, India +5.2M/yr: onboarding is the growth surface, yet no forge offers guided code-reading tours, "explain this PR/diff/CI failure" (OneDev gestures at it), mentorship queues, or portfolio/certification tied to real contributions.
18. **Federation that works on day one.** ForgeFed is still experimental after years (and can permanently break a domain); Tangled proves ATProto-based cross-instance identity and social graph at small scale. Offer cross-forge issues/PRs/identity plus bidirectional GitHub sync (as Origin does) so switching isn't all-or-nothing.
19. **Review quality over AI noise.** Independent testing shows AI reviewers with single-digit recall; HN calls GitHub's PR UI "dogshit" (hidden comments, lost scroll). Gerrit-grade inline review, CODEOWNERS gates (Gitea 28 just added), and honest AI assist is a defensible craft differentiator.
20. **Transparent, stable pricing.** GitHub's "$4/$21 for the first 12 months\*", GitLab's vanished Ultimate list price, promotional credit allowances, and surprise free-tier enforcement (Aug 15, 2026) all erode trust. Publish every price, commit to grandfathering (Sourcehut's model), and never meter customers' own compute.
