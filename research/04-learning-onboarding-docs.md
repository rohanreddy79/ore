## 1. Existing developer-learning products for git/DevOps

**GitHub Skills → "GitHub Learn".** Launched June 6, 2022 as successor to Learning Lab (https://github.blog/news-insights/product-news/introducing-github-skills/). Mechanics: learner clicks "Use this template", a GitHub Actions workflow prepares step 1 (~20s), checks the learner's commit/branch/PR, then rewrites the README with the next step; `introduction-to-github` has 10.7k stars / 19.5k forks (forks ≈ attempts) and targets "under an hour" (https://github.com/skills/introduction-to-github). As of Oct 2026, skills.github.com **redirects to learn.github.com/skills** (new "GitHub Learn" hub; launch date UNVERIFIED, page is JS-rendered). The `skills` org has 53 repos, ~21 tagged `skills-course`; almost everything updated in 2026 is Copilot/agent-centric (`idea-to-merge-with-the-copilot-app`, `agent-orchestration-build-your-ai-dream-team`, `copilot-code-review`, `agentic-workflows-that-read-the-room`), while the git basics (`introduction-to-git`, `resolve-merge-conflicts`) get maintenance updates only (https://github.com/orgs/skills/repositories). Known weakness: private-repo use burns Actions minutes, so courses tell learners to use public repos — i.e., the mechanism doesn't scale to enterprise-private learning.

**GitHub Learning Lab (retired).** Bot-driven courses inside real repos (2018). Deprecated Sept 1, 2022, repos archived (https://github.blog/changelog/2022-08-31-deprecating-learning-lab/). Official reason: "the best place to learn GitHub is on GitHub" and Skills is "backed by GitHub Actions" (i.e., they replaced a bespoke bot platform with their own primitives). Community asked to open-source Learning Lab; GitHub never did (https://github.com/orgs/community/discussions/24105). Lesson: a learning engine built on the forge's own automation primitives survived; the bespoke one died.

**GitLab Learn / GitLab University.** levelup.gitlab.com 301-redirects to levelup.edcast.com (third-party EdCast/Cornerstone LMS) — GitLab's learning is *outside* the product. Education services list eight private instructor-led courses (Fundamentals, CI/CD, Advanced CI/CD, Agile Portfolio Mgmt, Security Essentials, SysAdmin, Duo Agent Platform, Compliance) plus train-the-trainer; no public prices (https://about.gitlab.com/services/education/). GitLab Certified Git Associate: $150, 60 min, unproctored honor-code (https://www.cbtnuggets.com/blog/technology/programming/is-the-gitlab-certified-git-associate-worth-it).

**Katacoda (dead).** O'Reilly closed the public site June 15, 2022; stated reason: "crypto mining and other types of abuse" on free sandboxes required too many engineering/security resources; tech kept only inside paid O'Reilly (https://www.oreilly.com/online-learning/leveraging-katacoda-technology.html). Kubernetes.io's Katacoda tutorials died March 31, 2023 (https://kubernetes.io/blog/2023/02/14/kubernetes-katacoda-tutorials-stop-from-2023-03-31/). **Microsoft Learn sandboxes are also gone**: the Learn FAQ (updated 2026-07-29) says "Sandboxes are no longer available… you'll need access to an Azure subscription" (https://learn.microsoft.com/en-us/training/support/faq?pivots=sandbox). Pattern: free, anonymous, root-shell sandboxes die from abuse economics.

**Killercoda** (Katacoda's spiritual successor): FREE tier = unlimited free scenarios, 1-hour sessions, CAPTCHA; PLUS = 4-hour sessions, 3 concurrent, no CAPTCHA; COURSE adds CKA/CKAD/CNPE prep (official page lists no prices; directory says ~$19.99/mo — UNVERIFIED) (https://killercoda.com/pricing). Survives by gating session length, concurrency and CAPTCHA.

**Exercism**: 3,111,801 users, 72.3M submissions, 416,446 mentoring discussions, 19,603 mentors, 85 languages, 3 full-time staff, only 1% of users donate (https://exercism.org/about/impact). Sept 2024: "2M users but no money in the bank" — ~800 monthly donors, ~$7.5k/mo (https://exercism.org/blog/september-2024-restructure). Human mentoring at scale works pedagogically but not financially as a standalone.

**Boot.dev**: $399/yr; free mode is read-only after the first chapters; RPG mechanics (XP, bosses, "infinite challenges") (https://www.boot.dev/pricing). Revenue claims conflict wildly ($1.3M ARR per Latka 2024 vs $441k MRR/"$10M ARR" per Indie Hackers) — UNVERIFIED; >25k paying members (secondary). No completion data.

**Codecademy**: Skillsoft bought it for $525M (Dec 2021); **Feb 2026 Skillsoft laid off the entire Codecademy curriculum team**, framed as a shift to AI-led learning (https://www.edtechinnovationhub.com/news/skillsoft-lays-off-entire-codecademy-curriculum-team-senior-leader-confirms). Skillsoft quarter ended July 31, 2025: $128.8M revenue, subscription flat, non-subscription −8.4% (SEC 10-Q).

**freeCodeCamp**: v10 curriculum = 6–7 certifications, 100+ hands-on projects, 4 certs live by Dec 2025; 4,279 commits merged in 2025; 10,342 donors; claims 40,000+ learners got dev jobs (https://www.freecodecamp.org/news/freecodecamp-top-open-source-contributors-2025/).

**A Cloud Guru**: acquired by Pluralsight July 2021; ACG plans no longer sold; final platform shutdown reported Nov 4, 2025 (single source — UNVERIFIED); Pluralsight now lists "1,800+ hands-on labs" and Cloud Playground sandboxes (https://www.pluralsight.com/cloud-guru). **KodeKloud**: Standard ~$15–16/mo, Pro ~$21–26/mo, Business ~$330/user/yr; labs in paid tiers; free gamified "KodeKloud Engineer" (https://www.capterra.com/p/239528/Kodekloud/).

**roadmap.sh**: ~370K GitHub stars (6th most-starred repo), ~3.2M registered users, has a git-github roadmap (https://roadmap.sh/about). **Learn Git Branching**: 34.1k stars, 6.0k forks, 3,470 commits, MIT (https://github.com/pcottle/learnGitBranching). **Oh My Git!**: 2.9k stars, README says "low-maintenance mode" (https://github.com/git-learning-game/oh-my-git). **Git Immersion**: static lab sequence, "maintained with love", no dates (https://gitimmersion.com/). **Google Cloud Skills Boost**: ~$29/mo, pay-as-you-go $1/credit (https://cloud.google.com/learn/certificates). **Replit Learn** now sells four 30–45 min courses ("AI foundations", "Advanced vibes") — onboarding is about prompting, not coding (https://learn.replit.com/).

**Completion rates.** Jordan's 29-MOOC analysis: mean 6.8%; auto-graded 7.7% vs peer-assessed 4.8%; the outlier was EPFL's functional-programming MOOC at 19.2%, attributed to IDE plugins and automated graders (https://www.highereddive.com/news/new-data-reveals-low-mooc-completion-rates/129848/; https://graphsearch.epfl.ch/en/publication/190022). Claims of 58–72% completion for paid courses come from low-quality blogs — UNVERIFIED.

**What works / what died:** Survivors are (a) built on the host product's own primitives (Skills on Actions), (b) gated sandboxes (Killercoda), (c) hands-on with auto-grading (EPFL, Boot.dev). Deaths: free root sandboxes (Katacoda, MS Learn sandbox), bespoke bots (Learning Lab), human-curated curricula without a business model (Exercism's cash crisis, Codecademy curriculum team).

## 2. In-product onboarding & education best practices

**Benchmarks (2025):**
- Chameleon, 550M+ interactions: self-triggered tours get ~2× the engagement of auto-triggered; 4-step tours complete best, >5 steps loses more than half of users; tours launched from a checklist/launcher complete 67% vs 31% standalone (surveys 54% vs 15%); only ~23% of users open a launcher (27% with a welcome state), and those who do complete ~5 checklist items per session (https://www.chameleon.io/benchmark-report).
- Userpilot, 547 companies: activation avg 37.5% / median 37.0%; onboarding-checklist completion avg 19.2% / **median 10.1%**; time-to-value avg ~1.5 days (https://userpilot.com/saas-product-metrics/).
- Pendo, 6,800+ apps / 2,500 customers: best-in-class in-app guide engagement 60.2%, feature adoption 15.6%, stickiness 38%, time-to-value 0.2 days (https://www.pendo.io/product-benchmarks/).
Implication: checklists are the single best lever, but the *median* product only gets 10% to finish one, so the checklist must be short, self-triggered, and tied to real work.

**Developer-tool specifics.** "Time to hello world" / time-to-first-call is the dominant DX metric; vendor-circulated figures ("68% abandon trials over setup time", "first API call <10 min → 3–4× conversion", "Stripe/Vercel TTFAC <90s") are unsourced — UNVERIFIED (https://business.daily.dev/resources/developer-onboarding-optimization-from-first-click-to-paying-customer/). Stripe's docs now ship `stripe docs` (read docs in the terminal), `stripe agent setup`, agent skills (`/skills.md`), every page as `.md`, and an MCP server (https://docs.stripe.com/development) — docs are becoming an agent surface, not just a web page.

**Gamification evidence is weaker than its marketing.** Duolingo's "3× more likely to return daily with a streak" is company-reported; the "12%→55% retention" figure circulates without a dataset (UNVERIFIED). A systematic mapping study documents negative effects (superficial engagement, anxiety) of education gamification (https://arxiv.org/pdf/2305.08346). Use streaks/XP sparingly; auto-graded, real-task feedback is the evidence-backed mechanic (EPFL above).

**AI tutoring evidence (strongest in this slice).** Harvard CS50.ai (SIGCSE 2024): guardrailed GPT-4 "duck debugger" that *guides rather than answers*; >50,000 unique users and 1.8M queries by Dec 2023; 15–25K prompts/day; cost ~$1.90/student/month ($0.05/prompt); 88% accuracy on curricular questions; Fall 2023: 73% of students "loved"/"liked" it, 47% "very helpful"; usage throttled with "hearts" (10 hearts, +1 per 3 min) both for cost and to force reflection; forum answers are posted by the bot but **endorsed/edited/deleted by human staff** (https://cs.harvard.edu/malan/publications/V1fp0567-liu.pdf). Harvard physics RCT "AI Tutoring Outperforms Active Learning" (Kestin et al., Scientific Reports 2025, doi 10.1038/s41598-025-97652-6) — effect sizes not retrievable from the PDF here; UNVERIFIED magnitude (commonly cited as roughly double learning gains in less time). Counterweight: METR's RCT found experienced OSS devs were **19% slower** with AI while believing they were 20% faster (https://arxiv.org/pdf/2507.09089) — self-reported speedups are unreliable; measure.

## Design for teaching inside the forge — 22 evidence-backed recommendations

**Curriculum structure**
1. **Build the learning engine on the forge's own CI primitive, not a bespoke bot.** GitHub Skills (Actions-driven) survived; Learning Lab (bot) was killed and never open-sourced. Each lesson = a template repo + a pipeline that asserts state and rewrites the next step. Make it work on *private* repos without burning quota (Skills' known gap).
2. **Six tracks, mapped to the four $99 GitHub exam domains plus two gaps**: Git & forge basics, code review, CI/CD, deployment, security/supply-chain, admin. Mirror exam objectives so an internal credential has external currency (GH-900/Actions/GHAS/Admin; CKA/CGOA for deploy).
3. **Lessons ≤ 4 steps, ≤ 60 minutes, one real artifact each** (Chameleon: completion collapses past 5 steps; Skills' hour-long "profile README" deliverable).
4. **Auto-grade everything.** Auto-graded MOOCs out-complete peer-graded ones (7.7% vs 4.8%); the 19.2% outlier had graders and IDE tooling. The grader is the pipeline.
5. **Teach on the learner's own repo, not a toy.** Default lessons run against the org's real codebase via a fork/branch sandbox (e.g., "open a PR fixing this lint issue in *your* repo"), because time-to-first-commit (median 2–3 weeks) is the metric companies pay for.

**Mechanics & onboarding**
6. **One self-triggered onboarding checklist, surfaced in the repo sidebar, ≤5 items**: clone/push → branch → PR → review a PR → green pipeline. Checklist-launched tours complete at 67% vs 31%; median checklist completion is only 10%, so make items real work the user must do anyway.
7. **Instrument time-to-first-value per org**: first push, first merged PR, first green pipeline, first deploy. Publish the org's medians against anonymized benchmarks (DX-style) — this is the dashboard a CTO buys.
8. **Contextual "why did this fail?" teaching at the point of error** (merge conflict, failed job, blocked push by branch protection, secret-scanning hit) — a one-click "learn this" that opens the matching 4-step lesson. This is where CS50 saw value: instant clarification of *your* error, not generic content.
9. **Gamification: light.** Use progress/credentials and streak-free completion; avoid daily-streak pressure. Evidence for Duolingo-style streaks is company-reported, and negative effects are documented. Boot.dev's model works for self-paying hobbyists, not mandated corporate onboarding.
10. **Admin-assignable paths with cohort mode**: assign a track to a team, see completion, require "code-review" track before granting reviewer rights. This replaces $360–779/seat/yr library subscriptions and $1–2k/day ILT with a product feature.

**Sandboxes**
11. **Sandboxes are per-user, authenticated, time-boxed (≤1h free, 4h paid), concurrency-capped, CAPTCHA-gated, with egress blocked** — exactly Killercoda's surviving shape. Katacoda, MS Learn, and Codeberg Pages v2 all died or closed to new users from abuse; anonymous root shells are not viable.
12. **Prefer "sandbox = ephemeral CI job + ephemeral fork" over VMs**: the pipeline runner the org already pays for is the lab environment; lessons on deployment use a preview-environment job.
13. **Ship learning content and sandboxes inside the self-hosted binary** for air-gapped customers (GitLab Self-Managed/Forgejo users), with offline docs bundled; don't make lessons depend on a SaaS endpoint.

**AI tutor**
14. **Repo-aware tutor with CS50-style guardrails**: guides, hints, explains highlighted code and failed jobs; refuses to hand over full solutions during lessons; RAG over the org's own docs, ADRs, CI config and PR history; throttle with a visible budget (CS50 hearts; ~$0.05/prompt, ~$1.90/student/month in 2023 prices).
15. **AI answers in repo Q&A are provisional until a human endorses them** (CS50 Ed: bot answers, staff endorse/edit/delete). This rebuilds the Stack Overflow commons (down ~98% from peak) *inside* the forge with accountability, matching the 46% of devs who distrust AI accuracy.
16. **Auto-generate a DeepWiki-style "repo wiki" per repository on index, exposed via MCP** (three tools: structure, page, ask), refreshed on merge — DeepWiki proved demand (50k+ repos in months) but only for public repos; private is the enterprise gap.
17. **Measure, don't trust self-report**: A/B the tutor against docs-only on time-to-first-merged-PR (METR: devs believed +20%, measured −19%).

**Docs**
18. **Auto-build a docs site per repo with zero config** (detect `docs/`, mkdocs.yml, docusaurus, README) and render it next to the code TechDocs-style (Spotify: 5,000+ sites); emit every page as `.md`, plus `llms.txt`/`llms-full.txt` and an MCP endpoint (Stripe/GitBook pattern), knowing llms.txt is table-stakes signaling rather than traffic.
19. **Docs staleness signal in the PR**: flag docs pages untouched since referenced code changed; require a docs checkbox for public APIs. This is the structural fix for Confluence rot (no sourced stat, but the mechanism is clear).

**Credentials & localization**
20. **Issue Open Badges 3.0 verifiable credentials for completed tracks, free, signed by the forge, optionally co-signed by the org**; map to GitHub/GitLab/CNCF exam objectives and let orgs export to Credly/LinkedIn. OB3 is the direction (2.69M OB3 badges issued; 40% of platforms), while $99–$445 vendor exams remain the external benchmark.
21. **Localize the learning layer first, then the UI**: ship lessons and tutor in at least the 10 languages that cover the fastest-growing populations (Hindi, Bengali, Portuguese-BR, Indonesian, Spanish, Arabic [RTL], Swahili, Vietnamese, Chinese, Japanese), use Weblate/Crowdin community translation with reviewed suggestions (Forgejo/GitLab model), and show per-language completion % in-product. GitHub's English-only UI is the opening; GitLab's 78 locales are the bar.
22. **Low-bandwidth mode**: text-first lessons, no video dependency, offline-capable docs bundle, CLI-readable docs (`forge docs`, like `stripe docs`) so a developer on a 2G link or inside an air-gap still gets the full curriculum.

**Headline for the founder:** the market has already run the experiments — free sandboxes die of abuse, bespoke learning bots die of neglect, standalone curricula die of economics, and the public Q&A commons died of AI. What survived is learning built on the host product's own automation, auto-graded on real artifacts, gated sandboxes, and guardrailed AI with human endorsement. None of the incumbents ship that *inside the forge, on private repos, localized, offline-capable*. That is the gap.
